# Marketplace Frontend

Vue 3 + Vite scaffold for the WaviateScript marketplace UI.

## Commands

```powershell
npm install
npm run dev
npm run build
npm run preview
```

## Notes

- The app currently uses mock marketplace entries in `src/data/mockMarketplace.js`.
- Search, filters, pagination, upload CTAs, docs links, and desktop install buttons are UI-only.
- TODO comments mark backend integration points.
